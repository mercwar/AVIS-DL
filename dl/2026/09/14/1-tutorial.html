USER INTERFACE & DATA STORAGE:

This Quasar Stargate has open access and does not require a login. There are no user-level profiles or management features. Every uploaded record, artifact, and file is saved with a Permanent Face. New artifact submissions are the only methods available to correct Stargate errors.

File alterations are impossible. The system does not utilize user names, passwords, or security pins. Once processed, your file will immediately become available to the Quasar Application, resulting in either a VISIBLE STARGATE or NO VISIBLE GATE.

Any file that crashes a Gate must be saved as a NEW record, artifact, or file in the AVIS-DATALAKE along with the resulting crashed file chain using a different auto index that is applied when you save the files.
This means crashed file chains need to be uploaded in full within a different range of index.
The supporting application is the AVIS-DATALAKE Star Map Explorer.
By submitting a new list of Permanently Faced files individually, you would revise your quasar into a new artifact, only keeping the files that function properly.

The reason that these files are faced with a one-way door is simple: Avis-Datalake Free Pages does not ask you for your user name and password, so these records must be secure.
Stargate allows for saving the file. If you do not give away your keycode when saving Stargates, it is virtually impossible for the gate to be hacked. The Keycode acts as a temporary password
that waits for you to archive it. Once archived, you can give out the keycode. The Stargate includes Quasar pages, and the Quasar pages may link to Stargates with URL records.

Stargate records, `.sg` files, have a Keycode feature that allows them to be saved without archiving the artifact as well as being saved as an archived artifact and creating a Permanent Face for the Artifact listed in Nexus.

While `.quasar` files are not necessary to create HTML/DHTML applications on Avis-Datalake Free Pages and Stargate because Stargate files do allow for dynamic HTML content `.quasar` files are the only way to manage these web applications by way of Avis-Datalake Free Pages.

This is the File format:
[provided decimal number as auto index]-[title]-[protocol file extension if requested].[requested extension, otherwise json]
